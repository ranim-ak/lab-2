Ateliers hebdomadaires

Le club organise des ateliers pour aider les étudiants à développer leurs compétences informatiques.

Thèmes du semestre

  • Développement web
    • HTML

    • JavaScript
  • Programmation

    • Java
    • C

Hackathon

Le Hackathon est un événement qui permet aux étudiants de travailler ensemble sur un projet informatique.

Déroulement du Hackathon

  1. Inscription des participants.
  2. Formation des équipes.
  3. Développement du projet.
  4. Présentation des projets et évaluation.

Consultez le règlement de l'événement : Télécharger le règlement du club (PDF).
